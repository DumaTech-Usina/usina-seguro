A entrega é interna (in-app), como define REQ-102: a notificação aparece aqui, no sistema. E-mail, WhatsApp e demais canais entram como adapters do mesmo contrato (REQ-101, REQ-103), sem alterar a regra que dispara a notificação. Nada é marcado como lido: REQ-105 pede um registro do que foi notificado, não uma caixa de entrada com estado.
